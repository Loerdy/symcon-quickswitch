# symcon-quickswitch

IP-Symcon-Library **QuickSwitch**: Kachel für die Kachel-Visualisierung, in der verknüpfte Aktoren per Antippen geschaltet werden – mit Symcon-Icons oder eigenen Bildern, Darstellung An/Aus und optionalem Button „Alle an/aus“.

## Module

| Modul | Beschreibung |
| --- | --- |
| [QuickSwitch](QuickSwitch/README.md) | Eine Kachel pro Instanz mit beliebig vielen Aktoren (Boolean-Variablen mit Aktion). |

## Voraussetzungen

- IP-Symcon ab Version 8.2

Das Modul ist auf Deutsch und Englisch verfügbar (Sprache der Konsole bzw. Visualisierung).

## Installation

Die Library wird über das Module Control von IP-Symcon installiert:

1. In der Konsole unter **Kern Instanzen** die Instanz **Modules** öffnen.
2. Auf **+** klicken und die Repository-URL eintragen:

   ```
   https://github.com/Loerdy/symcon-quickswitch
   ```

3. Eine Instanz **QuickSwitch** anlegen („Instanz hinzufügen“, Suche nach „QuickSwitch“ oder „Schnellschalter“) und die Aktoren eintragen.
